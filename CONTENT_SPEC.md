# Learning Spectrum Content Specification
# K-5 NYS-Aligned Questions & Exercises

## Overview

This document defines the subskills, question types, and content structure for Learning Spectrum's K-5 practice system, aligned with **New York State Next Generation ELA & Math Standards**.

### Coverage Goals

- **Grades**: K through 5 (preparing for Grade 6)
- **Daily Practice**: ~30 minutes/day, 5 days/week
- **Task Duration**: 45-60 seconds per task
- **Tasks per Session**: 30-35 tasks (30 minutes)
- **Tasks per Week**: 150-175 unique tasks
- **Minimum per Category per Grade**: 60 unique items
  - 40 "core skill questions"
  - 20 "game-style practice exercises"

## 4. ADHD / 504 DESIGN PRINCIPLES

### Content Guidelines

1. **Short, Clear Prompts**
   - K-1: 1-2 short sentences max
   - 2-3: 2-3 sentences max
   - 4-5: 3-4 sentences max
   - Avoid multi-clause instructions for early grades

2. **One Concept at a Time**
   - Each question focuses on a single subskill
   - No "combo" questions that test multiple unrelated skills

3. **Neutral Feedback Language**
   - Wrong answers get: "Let's look at that one again together."
   - Right answers get: "You worked hard on that!"
   - Never: "That's wrong," "Try harder," "You should know this"

4. **Visual Support**
   - Use simple, clear graphics when helpful
   - Avoid cluttered or distracting images
   - High contrast, clean design

5. **Self-Advocacy Integration**
   - Preference questions scattered throughout
   - No right/wrong answers
   - Used to customize breaks, encouragement, supports

## 5. TTS (TEXT-TO-SPEECH) REQUIREMENTS

### Fields Required for TTS

Every question must include:

- `ttsPrompt`: Natural spoken version of the prompt
- `ttsAnswers`: Array of spoken versions of answers

### TTS Design Guidelines

1. **Natural Language**
   - Write as you would speak to a student
   - Avoid abbreviations (write "number" not "#")
   - Spell out symbols: "blank" for "___", "plus" for "+"

2. **Homophones Clarification**
   - If necessary, clarify: "Read the word r-e-a-d, like a book"
   - Or provide context: "Which word means to look at a book?"

3. **Voice Selection**
   - User selects: Male or Female voice (in setup screen)
   - User selects: Language (en, es, etc.)
   - System uses selected voice for ALL TTS

4. **Example**:
   ```json
   "prompt": "5 + 3 = ___",
   "ttsPrompt": "What is 5 plus 3? Choose the correct answer."
   ```

## 6. DIFFICULTY BANDS

Map difficulty to grade level for adaptive selection:

| Grade | Difficulty Range |

## 7. IMPLEMENTATION NOTES

### File Structure

```
/questions/
  ├── grade-K.js
  ├── grade-1.js
  ├── grade-2.js
  ├── grade-3.js
  ├── grade-4.js
  └── grade-5.js
```

Each file exports:
```javascript
export const gradeXQuestions = {
  reading: [...],
  understanding: [...],
  fluency: [...],
  math: [...],
  focus: [...],
  effort: [...]
};
```

### Randomization

- Shuffle `answers` array before display
- Use `correctAnswer` value (not index) to check
- Weight selection by `difficultyBand` relative to `gradeCurrent`

### Domain Mapping

Questions can tag multiple domains:
```json
"domains": ["math", "executive"]
```

This allows:
- Practice targeted to weak radar segments
- Cross-domain exercises (e.g., math word problems hit both math + reading)
